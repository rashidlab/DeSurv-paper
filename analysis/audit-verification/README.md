# Audit verification scripts (2026-10-04)

Supports `docs/plans/2026-10-04-audit-verification.md`. Read-only experiments on cached objects; no pipeline
script is run and nothing in `results/` is written. Run every script from the root of
`~/Downloads/DeSurv-paper-clean` (they read `results/*.rds` there). DeSurv 1.0.1 is the site library; scripts
that need 1.2.0 read `DESURV_120_LIB` (a library containing DeSurv 1.2.0, source DeSurv-clean 1f3d3f0).

| Script | What it does | Output kept |
|---|---|---|
| `f2/f2_lib.R` | Independent base-R Eq. 1 objective, full W gradient (incl. sd(Z) term), exact beta solver (FISTA), C-index | |
| `f2/f2_fast.R` | O(n log n) Breslow with exact ties, overrides the reference (checked to 1e-9 in item4_cv.R) | |
| `f2/f2_check.R <fit.rds> <label> [val_latent.rds]` | Objective match, FD gradient, feasible descent, beta KKT at lambda and 2*lambda, package beta routine, exact-beta C | `out_ms_101.txt`, `out_k2_120.txt`, `out_k12_120.txt`, `out_k12_nu0.txt` |
| `f2/f2_reopt.R <fit.rds> <label> <out.rds> [ntop] [maxit]` | Exact block descent of Eq. 1 from a fit; program overlap, train C | `reopt_ms.txt` (k3, 600), `reopt_k12.txt` (400), `reopt_k12_nu0.txt` (400), `reopt_k12_killed_at300.txt` |
| `f2/f2_val.R <reopt.rds> [ntop] [archived fit]` | External C with the production `compute_val_cindex` rule | `val_k12_nu0.txt` (k3 and k12 results are in the report) |
| `f2/item3_matched_beta.R` | DeSurv k3 vs alpha=0 fair comparator under a common second stage | `out_item3.txt` |
| `f2/item4_cv.R <n_part> <maxit> <ncores> <out.rds>` | 20-fold held-out C, stalled vs exact descent (run: `4 1000 16`) | `item4_full.txt`, `item4_full.rds` |
| `f2/run_nu0.sh` | nu = 0 k12 inline fit (1.2.0) and its probes | |
| `sub/` | Subagent F1/F5/F6 experiments (`cox101.cpp` = 1.0.1 `cox_suffix_stats_full`) | `../F1_F3-F7_verification.md` |

The k12 inline fits (`fit_k12_120.rds`, `fit_k12_nu0.rds`, 1.4 MB each) are not kept; they are regenerated by
`desurv_fit(..., k = 12, alpha = 0.658658, lambda = 0.74881, nu = 0.17285 or 0, lambdaW = 0, lambdaH = 0,
seed = 1, tol = 1e-7, maxit = 4000, ninit = 30)` under DeSurv 1.2.0 (see `run_nu0.sh`). Header lines of the
`out_*.txt` files record the session-scratch library path that was used.
| `regularization_design_memo.md`, `regularization/` | Exploratory future-estimator memo and its pilot runs (archived as run; not for this manuscript) | |
